SHARED MIDPOINT-SHARD SCAFFOLD INTERVENTION

Use two recursive subcalls to inspect complementary halves of the paper before
deciding the final spans. The recursive callable is available only inside
IPython as `rlm`; it is not a top-level tool.

In the first IPython action, execute this structural pattern:

```python
import asyncio
paper_text = open(
    "/workspace/evidence_context.txt", encoding="utf-8"
).read()
midpoint = len(paper_text) // 2
excerpts = [paper_text[:midpoint], paper_text[midpoint:]]
question = "the current user question"
prompts = [
    f"Return candidate verbatim evidence for {question!r} "
    f"from only this excerpt:\n{excerpt}"
    for excerpt in excerpts
]
children = await asyncio.gather(*(rlm(prompt) for prompt in prompts))
child_answers = [child.answer for child in children]
child_answers
```

The midpoint is determined only by paper length. Do not rank, omit, merge, or
reorder the two excerpts based on their content. Inspect both returned
`child_answers`, and independently verify every proposed final span by checking
that it occurs in `paper_text`. Child suggestions are not automatically correct.

After tool use, stop calling tools and state exactly one bare Python list of
verbatim strings, for example `["first exact span", "second exact span"]`.
Do not wrap the list in `FINAL(...)` and do not add prose. The deterministic
scorer parses only this bare-list payload.
